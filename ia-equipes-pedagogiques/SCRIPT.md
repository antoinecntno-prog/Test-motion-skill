# Script : Formation IA pour les équipes pédagogiques

Cible : directions d'établissement, coordinateurs et équipes enseignantes. Diffusion : page LinkedIn perso d'Antoine
Contino, formateur IA. Appel à l'action : réserver un appel (https://calendly.com/antoine-cntno/30min) ; lien école
antoinecontino.fr/ecoles.
Douleur : le temps des équipes part dans l'administratif (mails, bulletins, tableaux, réunions) et le sens s'use.
Promesse : du temps récupéré avec l'IA sur leurs vrais documents, et le sens du métier qui revient.
Vouvoiement. Voix Paul K (Eleven v4). Durée visée : 45 à 50 s.

## Concepts (un par ligne : l'angle, puis la dernière phrase)

1. **La salle des profs** : lundi soir, la salle vide, la pile de copies et de mails ; la même salle, animée, après la formation. « Le temps gagné revient aux élèves. Et le sens, avec. »
2. **Le compteur** : les heures de la semaine loin des élèves défilent ; le compteur se retourne. « Les heures reviennent dans la classe. »
3. **La case** : le métier se remplit case par case (bulletins, tableaux) jusqu'à ne plus laisser de place au cours ; l'IA remplit les cases, l'équipe reprend la page. « Il reste la page. La vôtre. »
4. **Le bulletin** : un seul bulletin, écrit le soir à la main ; le même, préparé avec l'IA et relu en deux minutes. « Même bulletin. Une soirée de plus. »
5. **La réunion** : la réunion qui prépare la réunion, puis la réunion où l'on parle enfin des élèves. « On a parlé des élèves. »

## Version A : « La salle des profs » (concept 1, touches du 3) · VALIDÉE le 06/10/2026

### Version mise en scène

| Partie | Voix | À l'écran (aquarelle, papier crème, bordeaux et ocre) |
|---|---|---|
| 1. Accroche datée | Lundi, dix-huit heures. La salle des profs est vide. Les copies sont encore là. | Une salle des profs à l'aquarelle, chaises rentrées, une pile de copies sur la table, l'horloge. |
| | Les mails aux familles attendent, les bulletins aussi. | Un portable ouvert : la boîte de réception, les objets des mails ; à côté, la grille des bulletins. |
| 2. Gag muet (2,5 s) | *(silence)* | L'horloge tourne, la pile monte d'un cran, la tasse de café refroidit (la vapeur s'éteint). |
| 3. Diagnostic | Vous avez choisi ce métier pour transmettre. | Un tableau à la craie, une main qui écrit, des élèves peints en taches ocre. |
| | Vous passez vos soirées à remplir des tableaux. | Le tableau noir devient un tableau de cases ; la main remplit les cases. |
| | Et le sens s'use, une case à la fois. | Les taches ocre des élèves s'estompent derrière la grille. |
| 4. Pivot sur noir | Et si vous repreniez ce temps ? | Noir, texte centré. 1,5 s de silence. Le papier revient, éclairé. |
| 5. Solution | Je forme vos équipes pédagogiques à l'IA, sur leurs outils et leurs vrais documents. | La même salle des profs, pleine, portables ouverts, les vrais documents sur la table. |
| | Un bulletin se rédige en quelques minutes. Une séquence s'adapte à chaque classe. | Un bulletin s'écrit à l'encre bordeaux, relu et corrigé d'un trait ; une séquence se décline en deux versions. |
| | Un mail difficile trouve son ton. Une grille d'évaluation se construit en direct. | Un mail se réécrit, plus court ; une grille se dessine ligne à ligne. |
| | Aucun prérequis technique : on part de votre quotidien. | Le carnet manuscrit : « vos documents, vos outils ». |
| | Le temps gagné revient aux élèves. Et le sens, avec. | Les cases s'effacent, les taches ocre des élèves reviennent, nettes. |
| 6. Marque et appel à l'action | Antoine Contino, formateur IA. | Signature manuscrite à l'encre bordeaux. |
| | Réservez un appel. | Bouton « Réserver un appel », clic ; dessous : calendly.com/antoine-cntno/30min · antoinecontino.fr/ecoles |

## Version B : « Le compteur » (concept 2, touches du 5)

### Version mise en scène

| Partie | Voix | À l'écran |
|---|---|---|
| 1. Accroche | Combien d'heures, cette semaine, loin de vos élèves ? | Un compteur d'heures peint à l'aquarelle, à zéro. |
| | Les mails. Les bulletins. Les tableaux. Les réunions qui préparent d'autres réunions. | À chaque mot, le compteur monte d'un cran ; une pile grandit à côté. |
| 2. Gag muet (2,5 s) | *(silence)* | Le compteur continue seul ; la salle des profs se vide chaise après chaise. |
| 3. Diagnostic | Ces heures, personne ne vous les rend. | Le compteur se fige, l'encre bordeaux coule. |
| | Et le cours, lui, se prépare sur un coin de table. | Un coin de table, une feuille, un café, l'horloge à vingt-deux heures. |
| 4. Pivot sur noir | Reprenons les heures. | Noir, texte centré, 1,5 s de silence. |
| 5. Solution | Je forme vos équipes à l'IA, ensemble, à partir de vos vrais documents. | La salle des profs pleine, les documents sur la table. |
| | Ce qui prenait une soirée prend une pause café. | La tasse fume à nouveau ; le bulletin est relu avant qu'elle refroidisse. |
| | Vous gardez la main : l'IA propose, vous décidez. | Une proposition à l'écran, un trait de stylo qui la corrige. |
| | Les heures reviennent dans la classe. Le métier retrouve son sens. | Le compteur redescend ; les élèves en taches ocre remplissent la page. |
| 6. Marque et appel à l'action | Antoine Contino, formateur IA. | Signature manuscrite. |
| | Réservez un appel, et retrouvez les plaquettes sur antoinecontino.fr. | Bouton « Réserver un appel », clic ; les deux adresses dessous. |
