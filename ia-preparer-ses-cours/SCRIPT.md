# Script : Préparer ses cours avec l'IA, et l'enseigner aux étudiants

Cible : enseignants et formateurs (lycées, écoles, universités), et les directions qui les accompagnent. Diffusion :
page LinkedIn perso d'Antoine Contino, formateur IA. Appel à l'action : réserver un appel
(https://calendly.com/antoine-cntno/30min) ; plaquettes sur antoinecontino.fr.
Douleur : le cours se prépare seul le soir, reste magistral, pendant que les étudiants ont déjà l'IA en poche.
Promesse : des cours interactifs préparés avec l'IA, et des étudiants qui apprennent à s'en servir pour progresser.
Vouvoiement. Voix Paul K (Eleven v4). Durée visée : 45 à 50 s.

## Concepts (un par ligne : l'angle, puis la dernière phrase)

1. **Trente téléphones** : le prof prépare le même cours que l'an dernier, la salle a déjà l'IA en poche ; il la fait entrer dans le cours. « Le cours redevient vivant. Et vous, disponible. »
2. **Le plan de cours** : une page qui n'a pas bougé depuis trois ans se réécrit chaque semaine avec l'IA. « Le plan de cours redevient vivant, chaque semaine. »
3. **L'interdiction** : le panneau « IA interdite » à la porte ; le même panneau retourné : « IA, entrez ». « Elle est entrée. La classe aussi. »
4. **Le quiz** : un cours magistral devient un quiz en direct, les mains se lèvent, les scores montent. « Trente mains levées. »
5. **Le binôme** : le prof et l'IA préparent à deux ; l'étudiant et l'IA révisent à deux ; le prof garde la dernière main. « À deux, on va plus loin. Vous gardez la main. »

## Version A : « Trente téléphones » (concept 1, touches du 4)

### Version mise en scène

| Partie | Voix | À l'écran (aquarelle, papier crème, bordeaux et ocre) |
|---|---|---|
| 1. Accroche datée | Mardi soir. Vous préparez le cours de demain. Le même que l'an dernier. | Un bureau de prof à l'aquarelle, une lampe, des diapositives qui défilent, identiques, datées de l'an dernier. |
| | Dans la salle, trente téléphones ont déjà une IA dans la poche. | La salle de classe dans la pénombre, trente écrans qui s'allument en taches ocre. |
| 2. Gag muet (2,5 s) | *(silence)* | Le prof fait défiler ses diapositives ; au premier rang, un pouce répond à un chat IA. Le tableau reste vide. |
| 3. Diagnostic | Vous l'interdisez. Ils s'en servent quand même. | Un panneau « IA interdite » collé sur la porte ; derrière la porte, les écrans brillent. |
| | Le cours avance au tableau, la classe est ailleurs. | Le tableau se remplit ; les têtes peintes regardent leurs poches. |
| 4. Pivot sur noir | Et si vous la faisiez entrer dans le cours ? | Noir, texte centré. 1,5 s de silence. Le papier revient, éclairé. |
| 5. Solution | Je vous montre comment préparer un cours avec l'IA. | Le bureau du prof, le soir ; sur l'écran, le plan de cours se construit à deux, la main du prof corrige. |
| | Un quiz en direct, un débat avec la machine, une étude de cas par équipes, une correction qui explique. | Quatre vignettes aquarelle qui s'ouvrent en éventail : les mains levées, deux bulles qui s'affrontent, quatre tables, une copie annotée. |
| | Vos étudiants apprennent à s'en servir pour progresser : des réflexes qu'ils garderont. | Un étudiant tape une question, vérifie une source, barre une réponse ; une tache ocre grandit sur son cahier. |
| | Vos contenus, vos objectifs : l'IA s'adapte à votre pédagogie. | Le plan de cours manuscrit du prof, l'IA en marge, en encre plus claire. |
| | Le cours redevient vivant. Et vous, disponible. | La salle pleine de couleur, trente mains levées, le prof au milieu des tables. |
| 6. Marque et appel à l'action | Antoine Contino, formateur IA. | Signature manuscrite à l'encre bordeaux. |
| | Réservez un appel. Les plaquettes sont sur antoinecontino.fr. | Bouton « Réserver un appel », clic ; dessous : calendly.com/antoine-cntno/30min · antoinecontino.fr |

## Version B : « Le plan de cours » (concept 2, touches du 5)

### Version mise en scène

| Partie | Voix | À l'écran |
|---|---|---|
| 1. Accroche | Un plan de cours tient sur une page. Celle-ci n'a pas bougé depuis trois ans. | Une page manuscrite jaunie, épinglée ; la date dans un coin. |
| | Vos étudiants, eux, ont changé d'outils. | Sous la page, des téléphones se mettent à jour, écrans en ocre. |
| 2. Gag muet (2,5 s) | *(silence)* | La page jaunit encore ; une punaise tombe. |
| 3. Diagnostic | Préparer et corriger : le soir n'y suffit plus. | Une pile de copies, une lampe, l'horloge à vingt-trois heures. |
| | Et devant l'IA, chacun bricole dans son coin. | Trois bureaux séparés par des cloisons, trois écrans différents. |
| 4. Pivot sur noir | Réécrivons la page. | Noir, texte centré, 1,5 s de silence. |
| 5. Solution | Je vous apprends à préparer vos cours avec l'IA, et à l'enseigner à vos étudiants. | La page blanche se réécrit à deux encres : la vôtre en bordeaux, l'IA en marge. |
| | Elle construit l'exercice, vous gardez l'exigence. | Un exercice proposé ; votre trait corrige l'énoncé. |
| | Ils apprennent à vérifier et à argumenter : des compétences pour la suite. | Un étudiant barre une réponse fausse et écrit la sienne. |
| | Le plan de cours redevient vivant, chaque semaine. | La page épinglée change de semaine en semaine, les couleurs se renouvellent. |
| 6. Marque et appel à l'action | Antoine Contino, formateur IA. | Signature manuscrite. |
| | Réservez un appel, et retrouvez les plaquettes sur antoinecontino.fr. | Bouton « Réserver un appel », clic ; les deux adresses dessous. |
